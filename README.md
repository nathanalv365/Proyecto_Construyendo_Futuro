# Proyecto_Construyendo_Futuro
Propuesta técnica para automatizar la digitalización de encuestas vinculadas al proyecto social "Construyendo Futuro", el cual se enfoca en la prevención del ingreso de jóvenes al sistema penal adolescente. Los documentos incluyen plantillas de evaluaciones de conocimientos y satisfacción, así como fotografías de formularios completados manualmente que sirven como base para el procesamiento de datos. Se plantean diversas rutas de desarrollo, desde soluciones sin código utilizando herramientas como Glide y Make, hasta arquitecturas personalizadas con React y Python. Un componente esencial del sistema es el uso de inteligencia artificial para realizar el reconocimiento óptico de caracteres, permitiendo extraer información de textos manuscritos. La propuesta destaca la importancia de un panel de validación humana para corregir nombres antes de sincronizar la información final con hojas de cálculo. De este modo, se busca optimizar la carga operativa y reducir los errores manuales en el registro de datos del programa.
